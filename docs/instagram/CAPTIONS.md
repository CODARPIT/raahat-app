## Real verified / false reports
When the control room marks a report **verified** or **false**, open that report's page in the control room ("Fact-check page" button), tap **Download Instagram card**, and post it with:

> ✅ Verified by the Raahat control room: [what happened], [area], [date].
> Check it yourself: raahat-kappa.vercel.app/v/[id]
> #Raahat #FactCheck

or

> ❌ FALSE: this photo is [old / not from here]. Please don't forward it.
> Check it yourself: raahat-kappa.vercel.app/v/[id]
> #Raahat #FactCheck

Never post a report that is still "Not verified yet".
